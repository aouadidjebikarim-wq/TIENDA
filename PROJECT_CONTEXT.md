# Tienda — contexto del proyecto

## Propósito

Este repositorio reúne los materiales de identidad y presentación para una tienda online de moda/ecommerce: propuestas visuales, logotipos, PDFs y scripts que generaron las revisiones.

## Contenido principal

- `assets/logos/`: propuestas de logotipo para la identidad `KA`.
- `assets/logos_luxury/`: propuestas de nombres e identidades de estilo lujo: Almaria, Amariel, Lunave, Solevia y Veloria.
- `output/pdf/`: entregables PDF finales.
- `tmp/pdfs/`: scripts de generación y PNGs de revisión de los documentos.

## Repositorio remoto

- GitHub: `git@github.com:aouadidjebikarim-wq/TIENDA.git`
- Rama principal: `main`
- El remoto se configura mediante SSH.

## Alcance y exclusiones

- `jarvis-asistente-ia/` no pertenece a este ecommerce y está excluido explícitamente en `.gitignore`.
- No añadir esa carpeta al repositorio salvo que se tome una decisión deliberada de integrarla.

## Cómo retomar el proyecto

1. Leer este archivo y `PROJECT_HISTORY.md`.
2. Revisar el estado con `git status`.
3. Consultar los PDFs en `output/pdf/` y, si se necesitan cambios, los scripts en `tmp/pdfs/`.
4. Confirmar la dirección de identidad elegida antes de crear nuevos recursos.
